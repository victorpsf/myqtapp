agora vamos fazer uma coisa maravilhosa, no menu lateral adicione:

 - chaves
   - criar chaves Asymetrica
   - criar criptografia de arquivos (Symmetric)
   - criar hash

dentro da tela de 'criar senha criptografada' de a opção de utilizar asymmetric ou symmetric

 - asymmetric 
   - de as opções de algoritmos de critografia asymmetric
   - de as opções de tamanho em caso da opção rsa de chave 512, 1024, 2048, 4096, 8192
   - opção de informar senha para criptografia asymmetric
   - após gerar as chaves de opção de escolha de pasta para armazenar as chaves criadas
 - symmetric
   - de as opções de algoritmos de critografia symmetric
   - peça a senha que vai ser utilizada para criptografar
   - peça o texto a ser criptografado ou arquivo
   - após informar o texto ou arquivo de opção de escolha de pasta para armazenar
   - em caso de arquivo o nome vai ser um hash do nome do arquivo original se tiver extensão (.pdf, .txt) preserve
 - hash
   - de as opções de algoritmos de hash
   - peça o texto a ser hasheado ou arquivo
   - apresente o resultado
